# create-node-express-backend

An automated CLI tool to instantly scaffold a pre-configured Node.js and Express backend project structure with essential dependencies.

## Folder Structure

```
<project-name>/
│
├── node_modules/
│
├── src/
│   ├── controllers/
│   ├── middlewares/
│   ├── models/
│   ├── routes/
│
|── index.js
|   
├── .env
├── .gitignore
├── package.json
├── package-lock.json
└── index.js
```

## Installation

You don't need to install this package locally with `npm install`.

Run it directly using **npx**:

```bash
npx create-node-express-backend <project-name>
```
